# Judging Criteria Mapping

- **Code Quality (20%)**: clean Flask app, separate static/templates, readable JS, documented README.
- **Algorithm Efficiency (20%)**: lightweight filtering; O(n) scan of recipe list; simple, fast.
- **Utilization of Tech Stack (14%)**: Python/Flask + optional OpenAI + IntaSend + (optional) Supabase.
- **Security & Fault Tolerance (12%)**: no PII; environment vars; offline fallback; graceful errors.
- **Performance (16%)**: minimal assets; simple render; no heavy dependencies.
- **Development Process (10%)**: team roles in README; docs folder; endpoints documented.
- **Documentation & Testing (8%)**: README + API docs + testing plan + checklist.
